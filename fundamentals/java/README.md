# Java Fundamentals

This directory is an independently buildable Gradle project for Java Kafka fundamentals examples.

## Prerequisites

- JDK 21
- Gradle Wrapper from this directory (`./gradlew`)

Gradle uses Java Toolchains and requests Java 21 for compilation. IntelliJ IDEA should import this directory from Gradle rather than from committed IDE metadata.

## Build

From this directory:

```bash
./gradlew build
```

From the repository root composite build:

```bash
./gradlew build
```
